# Tiny LLM на NVIDIA CUDA: учебный маршрут

Этот учебный маршрут адаптирует оригинальный [tiny-llm](https://github.com/skyzh/tiny-llm)
под Linux + NVIDIA RTX 3090. Оригинальные задания MLX/Metal остаются в своих папках,
а все задания для PyTorch/CUDA находятся отдельно.

**Начни здесь:** [docs/CUDA_START_HERE.md](docs/CUDA_START_HERE.md).

- [x] Week 1 / Day 1: подготовлены учебная заготовка, эталонная реализация, объяснение и тесты.

## Как проходить занятия

1. Открой описание урока, разберись с формулой и формами тензоров.
2. Запусти тесты эталонной реализации, чтобы проверить окружение.
3. Запусти тесты своей заготовки. Они **специально должны упасть**, пока TODO не реализованы.
4. Заполни TODO **сам**, запусти сначала тесты Task 1, потом Task 2.
5. Когда всё зелёное, сохрани изменения Git commit. После этого можно переходить к следующему уроку.

> Этот курс учит **LLM inference** и устройству GPU, а не тренировке весов модели.
> До Week 1 Day 5 настоящие веса Qwen3 скачивать не нужно.
